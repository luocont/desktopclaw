# 工具使用说明
工具签名会通过函数调用自动提供。
本文档记录一些不直观的约束条件与使用模式。

## 工作区沙箱（默认开启）
- `restrictToWorkspace` 默认为 `true`：文件与 shell 工具只能在**工作区**目录内读写、执行。
- 如确需访问工作区外的目录，请在配置 `tools.allowedPaths` 中显式列出（绝对路径或 `~` 开头），否则会被拒绝。
- 受限时：绝对路径、`..` 路径穿越、把 `working_dir` 指到工作区外都会被拦截。
- 这是为防止智能体污染电脑其他区域；不要试图绕过沙箱，确有需要请提示用户调整 `allowedPaths`。

## exec — 安全限制
- 命令可配置超时时间（默认 60 秒）
- 危险命令已被屏蔽（rm -rf、format、dd、shutdown 等）
- 输出内容超过 10000 字符时会被截断
- 受 `restrictToWorkspace` 沙箱约束（见上）

## cron — 定时提醒
- 使用方法请参考 cron 相关技能说明。
